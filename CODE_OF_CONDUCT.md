# Código de Conduta

O Pombo segue o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, acolha quem está começando, critique ideias e não pessoas, e não tolere
assédio, ofensas ou exposição de dados de outras pessoas.

Para relatar um problema de conduta, escreva para o mantenedor pelo
[formulário privado do GitHub](https://github.com/plagesribeiro/pombo/security/advisories/new) ou abra uma issue
pedindo um contato privado (sem detalhes). Todo relato é tratado com sigilo.
